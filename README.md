
# 📚 Biblioteca Virtual Educativa

## Descripción
Biblioteca Virtual Educativa es una aplicación de escritorio desarrollada en Java, cuyo propósito es facilitar la gestión y consulta de libros educativos mediante una interfaz gráfica.

El sistema busca organizar la información de los libros y facilitar su consulta por parte de los usuarios.

## Tecnologías utilizadas
- Java
- Java Swing
- Programación Orientada a Objetos (POO)
- IntelliJ IDEA
- Git y GitHub

## Funcionalidades
- Registro de libros.
- Consulta del catálogo.
- Búsqueda de libros.
- Gestión de préstamos y devoluciones.
- Interfaz gráfica de usuario.

## Ejecución
1. Descargar o clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Configurar el JDK de Java.
4. Ejecutar la clase Main.java.

## Objetivo académico
Este proyecto fue desarrollado como ejercicio académico para aplicar los conceptos de Java, programación orientada a objetos y desarrollo de interfaces gráficas.
